# 🚀 2D 종스크롤 슈팅게임 (Unity)

Unity로 제작한 **2D 종스크롤 슈팅 게임**입니다.  
기초 게임 구조, 이펙트, 아이템 시스템 등 슈팅게임의 핵심 요소들을 구현했습니다.

> 📺 참고 튜토리얼: [유튜브 영상](https://youtu.be/ETYzjbnLixY?si=5EF_jDQtLoHyTxEh)

---
## 🎮 주요 기능

- 🔫 **총알 발사 및 적 피격 처리**
- 💥 **폭발 이펙트 애니메이션**
- 🕹 **플레이어 이동 (방향키 기반)**
- 🌌 **무한 배경 스크롤 구현**
- 🍎 **아이템 획득 시 효과 적용**
- 🧱 **충돌 감지 및 적 제거**
